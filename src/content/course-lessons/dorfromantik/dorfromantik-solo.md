Dorfromantik: The Board Game is for 1 to 6 players, and solo is not a variant. The rules are the same at every count. You set up the same way, follow the same turn order rule for Task and Landscape tiles, score the same sheet, and mark the same Campaign sheet. The only thing missing is the conversation, and that is what this lesson replaces.

## Setting up alone

Set up exactly as the rulebook says: Task tiles in facedown stacks, Landscape tiles mixed with 3 returned to the box unseen, Task markers sorted by color, pads aside, boxes closed. Make the Landscape stacks easy to count, such as five stacks of 9.

Give yourself room. Solo games often end up with a sprawling map, because nobody is reaching across the table.

## Be your own table

In a group, someone usually spots the overshoot, the open Flag edge, or the Stream that will not fit. Alone, you need a habit that does that job. Before each placement, run three checks, out loud if it helps:

1. **The count.** How many tiles does each open task still need? Does this tile join two areas, and what is the new total?
2. **The edges.** Which edges does this tile leave facing empty space, and could a common tile fill them later?
3. **The second job.** What else does this tile do: close a Flag edge, extend the main Track or Stream, or set up a waiting area?

It sounds slow. After a few games it becomes quick, and it catches most of the mistakes a table would.

## Pacing a solo game

A solo game has the same number of placements as a group game, but no waiting for others, so it can go quickly. Resist that. The decisions are the same size as in a group game; you just make all of them.

A gentle rhythm works well: move fast through obvious placements, then stop and look at the whole map whenever a Task tile comes out or a stack runs empty. Those are the moments when plans change.

## Solo is practice

Solo games are good practice in Dorfromantik, for one reason: every decision is yours, so every result is easy to trace. Some ways to use that:

- **Try one principle at a time.** Play a game focused only on waiting areas. Then one focused on closing every Flag. Then one on the long lines. Compare the four review numbers from the [high score lesson](/academy/dorfromantik/dorfromantik-high-score-strategy/).
- **Keep a log.** Write the Task tiles revealed and the score for every solo game. A trend over five games tells you more than any single result.
- **Test a question.** Is it better to cancel a stuck task early or wait? Try it both ways across a few games and see which leaves more Task tiles in the box.

Skills carry straight back to group games. A player who has played solo will see the counts faster and can help a table without taking it over.

## A solo campaign

Your solo scores feed the Campaign sheet like any other. Two choices to make up front:

- **A separate campaign or a shared one?** If you also play with a group, you can run a solo campaign on its own sheet. The rulebook lets you pause one campaign and continue another, and each box's Components card shows what goes back where. Keeping them apart means your group still gets the surprises together.
- **Spoilers.** If you share a copy with a group, opening a box on your own solo campaign reveals it to you before your group sees it. Decide with them first.

## Keeping it relaxing

Dorfromantik is a calm game, and solo it can be the calmest hour of the week. If counting every edge takes the joy out of it, play some solo games for the pleasure of the map and some for score. Both count on the Campaign sheet.
