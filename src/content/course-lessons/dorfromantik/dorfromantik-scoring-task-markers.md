Welcome to Level 1. You can play a clean game now. The next step is knowing where points come from, because that changes almost every placement. This lesson walks through the Score sheet and then the one technique that does the most for your total: stacking tasks.

## The four lines of the Score sheet

At the end of a game in a fresh campaign, you score four things:

1. **Tasks.** Add up the numbers on every completed Task marker, sorted by type.
2. **Flags.** Each Flag in a closed territory scores 1 point per tile of that territory.
3. **Longest Track.** 1 point per tile in your longest unbroken Track.
4. **Longest Stream.** 1 point per tile in your longest unbroken Stream.

The rulebook's own example adds 42 points from 9 completed tasks, 5 from one closed Flag, 8 for the longest Track, and 5 for the longest Stream: 60 points. Tasks were 70% of that score.

## The ceiling on tasks

Each Task type has five markers: one 4, two 5s, and two 6s. That is 26 points per type and 130 if you completed all 25. Few games come close, but the number tells you something: a single completed task is worth 4 to 6 points, about as much as a closed Flag territory of the same size. And you get many more chances at tasks than at Flags.

## Every task is two rewards

A completed task pays its number. It also frees a slot. With fewer than 3 marked Task tiles on the map, the next turn reveals a Task tile instead of a Landscape tile.

That matters because the Landscape tiles are the clock. The game ends when you need one and the stack is empty. Task tiles are turns that do not use up the clock. So a group that finishes tasks quickly sees more Task tiles, places more tiles in total, and has more chances to score. The rulebook says it plainly in its tip on the ending: keep the number of unrevealed Task tiles as low as possible.

## Exact counts, and why to count twice

A marker needs exactly its number. One tile too many and it goes back to the box. The trap is that a single tile can add more than one to an area: if it touches two separate forests with Forest edges, they join, and the new territory is both forests plus the tile.

Count before you place. "This forest is 3, the one beside it is 2, and this tile joins them" means 6, not 4.

## Stacking: one territory, several tasks

A territory can hold more than one Task marker. When it reaches each marker's number, that marker completes and leaves. Then the territory keeps growing toward the next one. The rulebook's own example does this with a Stream: a 5 completes, and the same Stream goes on toward a 6.

That gives you the most useful habit in the game: **put tasks of the same type in the same area, in ascending order.**

Say a Grain field of 2 tiles carries a 4. A Grain Task tile with a 5 comes up. Place it in that field: it is now 3, still at or under both numbers, so it is legal. Add one more Grain tile and the 4 completes. One more and the 5 completes. If a 6 comes later, the same field can grow into it.

Two rules shape this:

- **Lower numbers must finish first.** Once a field passes 4, any 4 still on it is lost. And you cannot place a new Task tile with a 4 into a field that is already 5.
- **Equal numbers finish together.** Two 5s in one territory complete on the same tile. The rulebook gives this case directly: if both markers need the same count, one tile completes both.

## Tracks and Streams pay twice

A Track task and your Longest Track both count Track tiles. That looks like a conflict, since a task wants an exact length and the Longest Track wants length. It is not, because completed markers leave the map. Finish the Track task at exactly 5, then keep laying track: the marker is banked, and every new tile adds a point to your Longest Track.

The only danger is a Track or Stream that still carries an open marker. Extend it past that number and the marker is lost. Finish the task first, then stretch.

## What to aim for

You do not need a target score to improve. Track one number after each game: how many Task markers you completed out of the Task tiles you revealed. If that ratio climbs, your score will too.
