A library can hand you one book out of tens of thousands in two minutes because every book carries a short code that says where it lives and what it is. Tabletop games deserve the same. So we built a board game classification system of our own, and this article lays it out.

This is the second article in our Library Science for Gamers series. The pillar, [Organize Your Board Games by Role, Not by Box Size](/articles/organize-by-role-not-box-size/), makes the case for shelving games by the job they do on game night. The Ludarium Classification System takes that idea one step further: it gives each game a one-line code, so that two people who have never seen each other's shelves can compare them in a text message. It is also the backbone of the Ludarium app, which is in development and coming soon.

## Why does a board game need a classification system?

A library code does two jobs. It tells you where a thing goes, and it tells you what the thing is without opening it. "2-5 players, 30-60 minutes, ages 10+" is the closest thing a game box gives you, and it leaves out the parts that decide whether tonight goes well: how heavy the game feels, whether people are fighting or cooperating, and what role it plays in an evening.

A code that captures those things is useful on a single shelf. It becomes essential once you are sharing games across several homes, which is where [The One Copy Rule](/articles/one-copy-rule/) leads every play group eventually. "I have a medium-weight co-op for four that plays in an hour" is a sentence. A code is that sentence in six characters.

## The five dimensions of the Ludarium Classification System

Every game gets scored on five dimensions. Together they answer the five questions a group asks before pulling a box down.

### 1. Role on game night

What job does this game do? We use the seven roles from our starter shelf framework, each with a single letter:

- **G** Gateway. The first modern game you hand a newcomer.
- **F** Filler. Under 20 minutes.
- **D** Duo. Built for two, or best at two.
- **P** Party. Six or more, low rules overhead.
- **C** Co-op shelf role. The game you reach for when everyone wants to be on the same side.
- **S** Stretch. One step up from the group's comfort zone.
- **M** Multi-session. Campaigns and legacy games that continue across nights.

Role is the first character of the code because it is the first thing you shelve by.

### 2. Weight

How much does the game ask of the people playing it? A single digit from 1 to 5.

- **1** Teach in two minutes. Nobody needs the rulebook after the first round.
- **2** Teach in five to ten minutes. A newcomer can compete on the first play.
- **3** Teach in fifteen minutes. The first play is a learning play.
- **4** Expect a half-hour teach and a rules reference on the table.
- **5** Read the book before game night. Expect a long first session.

Weight is scored for your group, not from the box. A 3 for a table of veterans can be a 4 for a family table. Your code describes your shelf.

### 3. Player count range

The range your group actually plays, written as low-high, not the range printed on the box. If a game says 2-5 but is dull at two and chaotic at five, the honest code is 3-4. This dimension surprises most people, because it reveals how many "2-5 player" games are really 3-4 player games in practice.

### 4. Play length

Minutes for a typical game at your table, including setup and teardown, rounded to a useful step: 15, 30, 45, 60, 90, 120, or 120+. Your clock, not the publisher's; real play time usually runs well over the box estimate.

### 5. Interaction style

How do the players relate to each other?

- **X** Versus. Everyone competes; one winner.
- **A** Allied. Full cooperation; the table wins or loses together.
- **T** Teams. Two or more sides, cooperating within and competing across.

A few games blend these (a traitor in a co-op, for example). Code the dominant mode and let the shelf label carry the footnote.

## How the call number comes together

The full code reads: **role and weight, player range, minutes, style.** Four short blocks, separated by spaces, that fit on a strip of tape on a box spine.

`[Role][Weight] [Low-High] [Minutes] [Style]`

That is the whole system. It is short enough to write on tape and structured so the most important facts come first. Read the first two characters and you know where the game is shelved and how hard it is. Read the whole line and you know whether it fits tonight.

### A worked example: coding three games

Here is how three familiar games come out when scored by a typical four-person group that plays most Thursdays.

| Game | Role | Weight | Players (real) | Minutes (real) | Style | Ludarium code |
|---|---|---|---|---|---|---|
| Ticket to Ride | Gateway | 2 | 2-5 | 60 | Versus | `G2 2-5 60 X` |
| Pandemic | Co-op | 2 | 2-4 | 45 | Allied | `C2 2-4 45 A` |
| Codenames | Party | 1 | 4-8 | 15 | Teams | `P1 4-8 15 T` |

Read the codes aloud and you can hear the evening. `G2 2-5 60 X` is a light competitive game for a table of newcomers that takes about an hour. `C2 2-4 45 A` is the game you bring out when someone is having a rough week and nobody wants to beat anyone. `P1 4-8 15 T` is what happens when two extra people show up.

Now notice what the codes show that the shelf alone does not. None of the three is weight 3 or above, none is a duo, none is a stretch. The group's next purchase should probably start with an `S` or a `D`. That is a buying decision made from the codes, before anyone has walked into a store.

### Coding your own shelf

Scoring twenty games takes about half an hour the first time. For each game: assign a role letter based on when your group reaches for it, give it a weight for your group, write the player range and play time you actually experience, add the style letter, and put the code on painter's tape on the spine.

If a game resists coding, that is useful. It usually means it has not been played enough for anyone to know what it is, which puts it on the [Shelf of Shame](/articles/shelf-of-shame-infinite-cost/) and in line for a trade.

## How a shared code lets a group compare shelves

This is the reason we built the system instead of just recommending role-based shelving.

When every member codes their shelf the same way, the group can merge lists without being in the same room. Four friends each send a dozen lines of text. Someone pastes them into one list and sorts by the first character. Immediately, the group sees:

- **Duplicates.** Two people both own `G2 2-5 60 X`? Same role, same weight, same table, probably the same game. The [second-copy test](/articles/when-a-second-copy-is-worth-it/) applies, and one copy can be traded for something the group lacks.
- **Role gaps.** No codes starting with `D`? The group has nothing for nights when only two can make it. No `A` anywhere? The group has never played a co-op.
- **Weight ceilings.** If nothing on the merged list is heavier than 2, the group is ready for its first stretch game.
- **Length coverage.** A list full of 90s and 120s and nothing at 15 means the group has no filler for the half-hour before the last person arrives.

Each finding leads to an action. Trade the duplicate. Assign the gap to whichever member wants to [claim that lane](/articles/claim-a-lane/). Put the next purchase against the ceiling. Run the exercise twice a year with the [group shelf audit template](/articles/audit-your-group-shelf/), and the collection grows toward actual play instead of toward whatever was on sale.

A shared code also makes it easier to ask for what you want. "Anyone have a `D3` for Sunday?" is a question people can answer by glancing at their own labels. That is the point of a library: anyone can find anything, not just the person who shelved it.

## FAQ

### What is the Ludarium Classification System?

The Ludarium Classification System is a library-style code for tabletop games. Each game gets a short call number built from five dimensions: its role on game night, weight from 1 to 5, real player count range, real play length in minutes, and interaction style (versus, allied, or teams). The code fits on a box spine.

### How do you categorize board games?

Start with the job each game does on game night: gateway, filler, duo, party, co-op, stretch, or multi-session. Then add how heavy it is, how many people it seats in practice, how long it takes at your table, and whether players compete, cooperate, or play in teams. Those five facts describe almost any game.

### What does a Ludarium code like G2 2-5 60 X mean?

Read it in four blocks. `G2` means a gateway game of weight 2, easy enough for a newcomer to compete on the first play. `2-5` is the player range the group actually uses. `60` is the real play time in minutes. `X` means versus: everyone competes and one player wins.

### Should I use the box's player count or my own?

Use your own. The range printed on the box is the range the game technically supports. The range in your code should be the range your group enjoys. Many games listed as 2-5 are at their best at 3-4, and coding honestly is what makes the system useful for choosing a game on a given night.

### Can a group use one shared code for different shelves?

Yes, and that is the main reason to use it. When every member codes their games the same way, the group can merge lists by text message and sort by role. Duplicates, missing roles, and weight gaps become visible in minutes, which tells the group what to trade and what to buy next.
