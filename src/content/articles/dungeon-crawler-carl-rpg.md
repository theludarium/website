The World Dungeon from Matt Dinniman's novels now has its own tabletop roleplaying game. Renegade Game Studios publishes it in two main pieces: a Starter Set for the first floors and a Core Rulebook for the campaign beyond them.

**The quick answer:** a new group should start with the Starter Set, which runs the tutorial floors from the first book with Carl and Donut as characters. Buy the Core Rulebook when your group wants to make its own crawlers and keep going past the tutorial. Retailers list the Core Rulebook for release on November 23, 2026.

## The Starter Set

The Starter Set is the way in for players who have never touched the game. Its listing describes it this way:

- It covers the run through the **first two tutorial floors**, the same stretch as the opening of the first novel.
- **Carl and Donut** are playable characters, so you can start without building anyone.
- It is listed for **3 to 6 players, ages 14 and up**.
- It works with the Core Rulebook, so nothing you learn is wasted.

[Dungeon Crawler Carl RPG Starter Set](https://www.amazon.com/dp/B0GRW5H3RD?tag=cubecommonw0a-20)

## The Core Rulebook

The Core Rulebook is the full game, a large hardcover. Retailer and publisher listings say it includes:

- Character creation, skills, spells, and loot, plus tools for making your **own races, classes, and skills**
- Rules for the dungeon's neighborhoods, safe rooms, and monsters
- Everything you need to adventure through **floors three to five**

Renegade sells it directly, and most game stores can order it. If your local store hosts RPG nights, it is worth asking them first.

## Which one should you buy?

| Your group | Start with |
| --- | --- |
| New to tabletop RPGs | Starter Set |
| Read the books, want to play Carl and Donut | Starter Set |
| Experienced players who want their own crawlers | Core Rulebook |
| A group planning a long campaign | Both: the Starter Set as session zero, then the Core Rulebook |

## FAQ

### Is there an official Dungeon Crawler Carl tabletop RPG?

Yes. Renegade Game Studios publishes it, with a Starter Set and a Core Rulebook.

### When does the Dungeon Crawler Carl RPG Core Rulebook come out?

Retailers list it for November 23, 2026. Dates can move, so check with your store.

### Can you play as Carl and Donut?

Yes, in the Starter Set. It includes them as characters for the tutorial floors.

### How many players does the Dungeon Crawler Carl RPG need?

The Starter Set is listed for 3 to 6 players. Check the box for whether that count includes the game master.

### Is the Dungeon Crawler Carl RPG for kids?

The Starter Set is listed for ages 14 and up, and the books are written for adults. Treat it as a teen and adult game.
