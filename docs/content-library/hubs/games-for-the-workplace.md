# Games for the Workplace

Team building board games work because a game table makes people show you how they operate. In forty-five minutes of Pandemic you see who leads, who defers, who steamrolls, and who notices the quiet person with the right answer. A workshop asks people to describe themselves. A game makes them do it in public, with low stakes and a lot of laughing.

This category is for managers, HR leads, and the one person on every team who gets handed the offsite. The core question is practical: how do I run a game session at work that people do not roll their eyes at, and what will it actually tell me?

The answers start with picking the right game for the goal. Codenames shows how a team communicates under time pressure. Negotiation games give sales teams real practice making offers and walking away. Cooperative games build psychological safety faster than any slide deck, because mistakes are cheap and everyone makes them in front of each other. The twenty-game roundup is sorted by group size and purpose so you can match a game to the afternoon you have.

Then the logistics. What a corporate game night costs, with rough per-person ranges for doing it yourself, hiring a host, or buying the full service. How to use a remote team's one in-person day so people leave knowing each other instead of the agenda. How to fold a game night into onboarding, and how to start a lunch-hour game club that outlives its founder.

If you are planning an offsite, start with the trust-fall piece and the twenty-game list. If you want to read your team, start with Codenames and the leadership piece on Pandemic. If you are costing it out, the breakdown is near the bottom of the list.
