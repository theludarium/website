# Game Night Programming

A game night is one evening. Programming is what turns it into a habit for other people. This category is for hosts, venues, libraries, churches, offices, and anyone else who wants a room to fill on a schedule. It covers the formats that work, the ones that quietly fail, and the details that make the difference: scoring rules, room layout, staffing, and what to say at the door.

The formats are the heart of it. Themed nights, with twelve themes that are more than "bring a game" and the one rule that makes each one work. Tournaments, with brackets, seeding, Swiss pairings and tiebreaks explained so that nobody argues at the end. Leagues, which need a scoring rule that survives missed weeks or they die in month two. Trivia night, puzzle night, learn-to-play events, drop-in RPG one-shots for strangers, and a kids' afternoon that parents will thank you for.

One piece is about scale. Running a game night for forty people is not running a game night for eight five times. It needs a room plan, a game mix, and a schedule. That guide is the one to read before you say yes to a large event.

The last piece ties it together: a full year of game nights, one themed night per month matched to its season, with the games and the reason each one lands when it does. If you only read one thing here and you run a venue, read that.

Every guide assumes you are working with limited volunteers, a real budget, and people who might not come back. That last constraint is the one that matters. The test for any program is whether the same faces are there in week six. Everything here is built to pass it.

This is also the category behind The Ludarium's own events, including the corporate game nights we run now and the lounge calendar we are planning. We are writing down what we learn as we learn it.
