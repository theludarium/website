# Tabletop RPGs for Beginners

A tabletop RPG is a game where a group tells a story together, one person describes the world, and dice decide what happens when the outcome is in doubt. Dungeons & Dragons is the famous one. It is not the only one, and it is not always the easiest first one.

This category exists for the person who has watched Stranger Things or Critical Role and thought, I would try that if someone would just tell me what to do. So that is what these pages do. No homework, no 300-page rulebook, no assumption that you own dice.

The core question is how to get from curious to sitting at a table in one evening. The answer is a one-shot: a single-session adventure with pre-made characters, run by someone who has done it before. The pieces here explain what happens at the table, what the seven dice are for, what advantage means, and the four things to know before your first session. There is also a guide to finding a group as an adult, with seven places that reliably work and how to tell a good table from a bad one in a single night.

Some of you will get volunteered to run the game. That piece is here too, written for the first-time Dungeon Master who has three days and a mild sense of dread. Some of you will freeze when the GM turns to you and asks what your character does. Six moves that always work are in the roleplaying tips.

If D&D feels like too much, the roundup of eight easy systems covers games you can learn in an hour, several of them better fits for a first night than D&D itself. Parents will find a guide to running an RPG for kids, with the table rules that keep it fun past the first twenty minutes.

Start with the plain explainer if you have never seen one played. Start with the first-time D&D guide if you have a session coming up. Start with the one-shot piece if you are the one organizing.

RPGs are the purest form of togethering we know. Four people, a table, and an imagined place that only exists because all of you are there to hold it up.
