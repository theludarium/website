# The Ludarium brand marks

Files live in `public/brand/` (served at theludarium.com/brand/). The mark is a flat-top hex tile with a round table and six chairs cut out of it.
The cut-outs are transparent, so place the mark on any background.

| File | Use on |
| --- | --- |
| `ludarium-mark-felt-green.svg` | Parchment or white (default) |
| `ludarium-mark-walnut.svg` | Parchment, light photos |
| `ludarium-mark-parchment.svg` | Walnut, Felt Green, dark photos |
| `ludarium-mark-lamplight.svg` | Walnut only, for special moments |

Colors: Walnut #2B1E16, Parchment #F6EFE3, Felt Green #2F5D50, Lamplight #E0A23B, Stone #B9AD9C.
Keep clear space around the mark of at least one chair's length on every side.
